🔑 DPoP — Demonstrating Proof of Possession (RFC 9449) ⬤ Active
ℹ️
Token-Binding Security
DPoP cryptographically binds access tokens to a key pair stored in your browser. Even if a token is stolen, it cannot be used without the private key.

How DPoP Works
1. Browser generates EC P-256 key pair
2. Private key stored securely (non-extractable)
3. Public key sent with token requests
4. Auth server binds token to public key (cnf.jkt claim)
5. Each API request includes signed DPoP proof
6. Resource server validates proof matches token binding
